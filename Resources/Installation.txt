ScreenOff 1.3.3, build 14 — fork prerelease RC1

Download: https://github.com/alexstonelunde/ScreenOff/releases/tag/v1.3.3-rc.1
This release candidate includes the four audited recovery fixes. Physical
sleep/wake acceptance on the Belkin/LG setup remains outstanding.

INSTALLATION
When updating, first quit the old version using the power button in its window.
1. Drag ScreenOff.app into Applications and replace the previous app if prompted.
2. Open ScreenOff from Applications or Spotlight (⌘Space → ScreenOff).
3. There is one switch: “Use built-in display” with an external monitor.
   • On: use both displays.
   • Off: automatically disable the MacBook display with an external monitor.
   Without an external monitor, the built-in display is restored.

ScreenOff has no menu bar or Dock icon. Open it through Spotlight or
Applications to access settings. Closing the window leaves the app running
in the background. Your display preference is saved.
Switching to another application, including changing Stage Manager groups,
automatically hides the window. Display control continues in the background.
Reopen ScreenOff through Spotlight to bring settings back.

Turning the switch off also registers ScreenOff to launch at login.
macOS may ask you to allow it in System Settings → General → Login Items.
Turning the switch on restores the display and removes this login registration.
Settings do not open automatically at login.
When updating from the original two-switch interface, the former automatic-off
option being enabled corresponds to “Use built-in display” being off.

If Gatekeeper blocks the app, attempt to launch it, then open
System Settings → Privacy & Security → Open Anyway.
The build is ad-hoc signed, without an Apple Developer certificate or notarisation.
Do not disable macOS security or SIP. Running the app needs no administrator password.

HOW IT WORKS
Disabling removes the built-in display from the active macOS desktop.
Windows move to the external monitor. Brightness and display colours are unchanged.
Disconnecting the last external monitor restores the built-in display.
An open lid keeps the keyboard, trackpad, camera and Touch ID accessible.
Quitting ScreenOff restores the display. Use the power button in settings to quit.
Your preference also applies the next time an external monitor connects.

The app uses a private macOS API; operating system updates may affect its behavior.
If the API is unavailable, ScreenOff prevents disabling and explains why.
If display mirroring is enabled, turn it off in macOS Display settings first.
Windows may remain on the external monitor after the built-in display returns.

RECOVERY
A confirmed disable is preserved while the same user owns the locked console
and through display/system sleep. If macOS reactivates the internal panel after
wake, the helper can reapply disabling after checking the external monitor.
Closing the lid or losing console ownership requests recovery; with the lid
closed, recovery waits until it opens.
Display changes run in an isolated child with a three-second timeout; the rescue
supervisor remains responsive if a system call stalls. Sleep or lid closure can
cancel the child. A timed-out change waits for a real wake/lid/session/topology
transition before retrying, avoiding a continuous retry loop.
When the external monitor disconnects, an independent recovery process restores
the built-in display while the app observes its result. Protection also covers an app crash or
unresponsive main process. No separate persistent services need to be installed.
Recovery remains armed through temporary display disappearance, sleep and lid
closure until the built-in display is confirmed active with the lid open.
With the lid closed, recovery waits without sending display-configuration commands.
It resumes when the lid opens. Neither the main app nor the supervisor enters
a display-configuration call directly.
This also applies when the Mac
stays awake on mains power while the connected external monitor sleeps.
If macOS stops enumerating the built-in display after cable removal, ScreenOff
can enable it using its last confirmed identifier. The macOS virtual placeholder
is not counted as an external monitor.
After recovery, automatic disabling resumes on the next monitor connection or
after unlock/wake. The switch can also reapply your choice. No new disabling
is attempted until restoration is confirmed.
If the display does not return, open the lid, reconnect the external monitor
and run this command in Terminal:
  /Applications/ScreenOff.app/Contents/MacOS/ScreenOff --recover
The command observes recovery within a shared twelve-second budget using
disposable read-only helpers. An accepted recovery supervisor can continue after
the command exits. A helper that misses all its own wake notifications may still
need a recognised wake or lid transition before recovery resumes.
If macOS no longer responds to the API, log out or restart the Mac.

UNINSTALLING
If you configured any optional Night Shift exclusions, restore them in ScreenOff
and restart first. These model-specific display overrides persist after quitting
or deleting the app; applying or restoring an override asks for administrator
approval and a restart.
Turn on “Use built-in display,” quit ScreenOff with the power button and delete
ScreenOff.app from Applications. No system drivers are installed.
